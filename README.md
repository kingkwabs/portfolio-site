# Kwabena Appiah Portfolio

A Frontify-inspired portfolio site for Kwabena Appiah, built with React, TypeScript, and Vite.

Live site: https://kingkwabs.github.io/portfolio-site/

## Highlights

- Interactive project network for Field AI, IDC Energy, CivSim, PLANETOIDS, and McDiver
- Resume-driven experience, education, skills, and contact sections
- Magic-UI-inspired motion patterns: breathing grid, particles, marquee, and border beam
- Downloadable resume asset at `/Kwabena-Appiah-Resume-Dec-2025.docx`
- Responsive layouts tuned for desktop and mobile

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npm run build
```
